Forecasts every GTA VI trophy's Exophase earn rate one week after launch (26 Nov 2026) as five quantiles, from the trophy page's recorded history up to the entry deadline. Damped log-time trend per trophy plus a counts view (earners / players tracked), with shrinkage toward the global slope and a spread that widens like a random walk.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
